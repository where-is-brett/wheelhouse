## Wheelhouse

This project runs Wheelhouse at Lean. Every message from the director goes first through Wheelhouse, whatever it asks for, including a small change to one file. Before you read, search or change any file of the product, load the skill `wheelhouse-lean` and follow its Intake at Lean. Don't edit the product's files straight away, and don't skip the cards. If the skill isn't there, say so in one line and stop: the director can ask you to set up Wheelhouse again.
