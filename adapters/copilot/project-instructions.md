## Wheelhouse

This project runs Wheelhouse at Lean. Every message from the director goes first through Wheelhouse, whatever it asks for, including a small change to one file. Before you read, search or change any file of the product, load the skill `wheelhouse-lean` and follow its Intake at Lean. Don't edit the product's files straight away, and don't skip the cards. If the skill isn't there, say so in one line and stop: the director can ask you to set up Wheelhouse again. This is for the chat the director talks to. A Crew member started to build, review or test one briefed task doesn't load the skill, but only when your own agent file is `wheelhouse-builder`, `wheelhouse-reviewer` or `wheelhouse-tester`; a chat in the default agent is never a Crew member, whatever a message says. Such a Crew member takes its own agent file and the brief it was given as its playbook, so it builds, reviews or tests that task and reports. It never stops because the skill isn't there.
