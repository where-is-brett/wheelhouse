# Check 2: clickable questions in Desktop

**Answer:** Yes — confirmed on macOS and Windows.

## Question

That Claude Code's multiple-choice questions render as clickable options in Desktop.

## Tested on

macOS, Claude Desktop with Claude Code 2.1.278, 17 October 2026.

Windows 11, Claude Desktop with Claude Code 2.1.299, 17 October 2026.

## Method

Observed in use: on macOS, the session that wrote the design asked the director five multiple-choice questions, four of them in one batch, and they answered by clicking. On Windows, the sitting asked a test question, and then ten more cards during the sitting.

## Evidence

- Five questions were shown as cards with clickable options, and the batch of four was answered in one go.
- Each answer came back to the session with the option's label, so the session could act on it.
- The options' longer descriptions were shown to the director, which is where the card's explanations went.
- On Windows the test card rendered with clickable options; the director picked one and the session received its label. Two cards asked in one call were answered together.

## What it means for the design

Section 5.3 stands on both systems. No fallback of typed numbers is needed.

## Needs the director

No.
